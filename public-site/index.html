01 · Capabilities

Everything a chief of staff would do

74 desktop actions wired into one voice interface — plus a Drive where JARVIS builds websites and files for you. Natural-language AI can rotate across configured OpenRouter, NVIDIA NIM, and Google Gemini keys; exact computer actions execute locally with risk-aware approvals.

Voice-First Control

Hold the talk key, speak naturally, release. JARVIS parses intent and executes — no menus, no typing, no digging through System Settings.

68+ Desktop Superpowers

Launch apps, control volume, zip files, search the filesystem, snap screenshots, toggle Dark Mode. If a chief of staff would do it, JARVIS does it.

AI Concierge Customer Service

Stuck? Talk to the built-in concierge. It walks you through features, troubleshoots live, and escalates to a human when you genuinely need one.

Multi-Provider AI Failover

Cloud AI rotates across OpenRouter, NVIDIA NIM, and Google Gemini keys. If a provider times out, rate-limits, or returns an unreadable answer, JARVIS tries another configured route. If every cloud provider fails, it reports the failure instead of substituting a local answer brain. The key pool stays local to each installation in this build.

Military-Grade Safety Engine

Every command is risk-tiered. Reading a file? Silent. Deleting a folder? JARVIS asks twice. Destructive actions always require your confirmation.

⌘K Command Bar

Prefer typing? A Stark-grade command bar sits one shortcut away — fuzzy search across every automation in the arsenal.

Productivity Studio

Tasks, notes, and reminders in one holographic workspace. Capture by voice, review by keyboard, and finish the day actually done.

6 HUD Themes + 4 Visual Avatars

Dress the interface. Six HUD themes and four visual avatars — from minimal tactical to full Iron Man theater mode.

Works Offline

Connection dropped? The offline fallback brain takes over — apps, volume, files, and system controls keep running at full speed.

Cross-Platform

Native automations on macOS Sonoma+ and Windows 10/11. One voice, one experience, on both of your machines.

Privacy First

Everything executes on YOUR machine. No telemetry, no screen scraping, no uploads of your files. Your computer stays yours.

One-Command Launch

One file, one command, one second. The launcher verifies dependencies and boots the HUD — no installers, no configuration.

Never paste API keys into a chat, public website, or GitHub repository. The local Admin → AI Keys screen accepts them in a password-style field and only shows a fixed hidden label and opaque removal ID; it never shows key fragments. Raw key values are not part of this website, its HTML/JavaScript, or release ZIPs. Keys stay on the local installation; a centralized cloud key service is not included in this static website package.
